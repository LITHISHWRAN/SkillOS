# React Code Review

## Objective
Review React code and report meaningful issues supported by evidence.

## Workflow
1. Inspect the component and relevant dependencies.
2. Check state management, error handling, and accessibility.
3. Report findings with severity, location, explanation, and suggested fix.

## Constraints
- Do not invent bugs.
- Separate confirmed defects from potential risks.
- Avoid unnecessary rewrites.
